## 保护模块移除

- 删除 `payload/obfuscation.h`、全部字符串混淆包装及 CMake 的混淆开关，直接使用字符串字面量。
- 删除 `injector/payload_crypto.*`、`injector/sha256.*` 及相关测试，移除 AES-256-GCM、拆分密钥、随机 nonce、认证 tag 和运行时 payload 哈希认证。
- `gen_payload` 直接生成 `kPayloadData` 原始字节数组；注入器将该数组交给现有加载器。
- 嵌入引导写出的运行 DLL 改为普通文件属性，并兼容覆盖旧版本的隐藏运行 DLL。
- 保留现有独立注入器和游戏 EXE 嵌入功能，并维护原子替换、部署失败回滚、原版备份和来源哈希清单。

本次扫描未发现第一方源码中的反调试检测、商业保护器调用、其他字符串加密或控制流混淆实现。
Windows 内存访问检查、编译器内存安全选项、配置损坏检查和备份哈希用于稳定运行与文件恢复，继续保留。
