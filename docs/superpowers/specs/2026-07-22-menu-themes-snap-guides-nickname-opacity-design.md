# 菜单主题、四宫格吸附与昵称不透明设计

## 目标

为主菜单增加关闭按钮和独立设置，给可移动功能窗口增加全屏四宫格参考线与智能吸附，并删除玩家昵称的遮挡透明逻辑。

## 菜单关闭按钮

- 主菜单标题栏右上角显示标准关闭按钮。
- 点击关闭按钮只隐藏主菜单，不关闭功能、不卸载模块。
- 按 U 键可重新打开主菜单。
- 菜单显示状态不持久化，进程启动时仍默认显示。

## 菜单设置

- 功能列表首项新增“菜单设置”，并作为菜单首次打开时的默认选中项。
- 菜单设置包含“参考线”复选框和“主题颜色”下拉框。
- “参考线”默认开启；关闭后同时禁用参考线绘制和智能吸附。
- “主题颜色”选项为“暗色”“亮色”“深蓝”，默认“深蓝”。
- 主题只改变主菜单窗口及菜单控件，不改变功能浮层的用户颜色、文字、背景或高光。
- 主题选择后立即应用。

## 主题

- 暗色主题以 ImGui 暗色为基础，保留现有圆角和间距。
- 亮色主题以 ImGui 亮色为基础，保证标题、列表和控件对比度。
- 深蓝主题以暗色为基础，使用深蓝窗口背景、蓝色选中项和蓝色控件强调色。
- 每帧绘制功能浮层前恢复通用暗色基础；绘制主菜单时局部应用菜单主题，避免主题污染功能浮层。

## 配置兼容

- 在 Settings 中新增菜单设置结构，保存参考线开关和主题枚举。
- 配置版本从 V6 升级到 V7。
- 保留精确的 V6 结构用于迁移；读取 V6 时复制全部旧设置，菜单设置使用默认值：参考线开启、深蓝主题。
- V1 至 V5 的现有迁移继续有效，并最终使用相同菜单默认值。
- 读取 V7 后规范化参考线布尔值和主题范围。

## 可移动功能窗口

- 吸附仅应用于圣木计时器、游戏时间、鬼魂状态、十字架计时器、准星信息和物品栏。
- 主菜单、屏幕准星和玩家昵称不参与吸附。
- 六个功能窗口统一向 Overlay 返回稳定 ID、实际 Bounds、是否允许移动以及位置提交能力。
- 只有未固定、按住 Alt 且当前窗口实际被鼠标拖动时，才显示参考线并计算吸附。
- 窗口未被拖动、Alt 松开、鼠标松开或参考线关闭时，不显示参考线且不改变位置。

## 四宫格参考线

- 使用前景绘制列表绘制全屏水平中线和垂直中线，将屏幕分为四个象限。
- 参考线绘制在功能浮层之上、主菜单之下。
- 常规参考线使用低透明度细线；命中的轴或吸附点使用更高透明度强调。
- 参考线颜色固定为清晰的青蓝色，不随菜单主题变化。

## 智能吸附

- 吸附按窗口中心计算，不按窗口左上角计算。
- 二维候选点包括四个象限中心和屏幕中心：
  - `(W/4, H/4)`
  - `(3W/4, H/4)`
  - `(W/4, 3H/4)`
  - `(3W/4, 3H/4)`
  - `(W/2, H/2)`
- 屏幕四边按窗口相应边缘吸附到 `x=0`、`x=W`、`y=0`、`y=H`。
- X 和 Y 轴可以独立吸附。
- 进入阈值为 10px，释放阈值为 16px，并为当前拖动窗口保存轴向吸附状态形成滞回。
- 二维候选在双轴同时进入阈值时优先；多个候选满足时选择欧氏位移最小者。
- 单轴候选满足时选择该轴绝对位移最小者。
- 吸附结果最后经过 ClampPosition，保证窗口完整位于屏幕内。
- 拖动过程更新内存位置；停止拖动后现有延迟保存机制写入配置。

## 玩家昵称

- 删除从摄像机到玩家头部的 Unity Physics 射线检测。
- 删除 Ray、RaycastHit、PhysicsScene、Collider 和 Player 类型等仅供昵称遮挡使用的 API 解析。
- 删除遮挡层数和 `OcclusionAlpha` 映射。
- 玩家昵称最终透明度始终等于玩家昵称设置颜色的 alpha。
- 保留远端存活玩家过滤、头部定位、世界到屏幕投影、距离计算、距离字号缩放和高度偏移。
- 删除昵称遮挡后不再需要为识别射线目标额外寻找本地 GamePlayer。
- 准星信息和物品栏使用的 GetComponentInParent 不受影响。

## 测试与验证

- 纯逻辑测试覆盖四象限中心、屏幕中心、四边、X/Y 独立吸附、最小位移、10px 进入阈值、16px 释放阈值和最终 Clamp。
- 测试参考线关闭时不发生吸附。
- 配置测试或结构断言覆盖 V7 默认值、主题规范化和 V6 到 V7 迁移。
- 删除 OcclusionAlpha 旧测试，并静态确认昵称模块无 Physics Raycast 残留。
- 验证菜单 X 仅隐藏菜单且 U 可重开。
- 验证三种主题只影响主菜单。
- Debug、Release 构建和 CTest 均通过。
- 最终构建到 `K:\ToolsBOX\out\bin\Release\PhasmophobiaInjector.exe`。
- 不执行游戏注入；游戏内拖动、参考线、吸附、主题和昵称显示效果需实际运行确认。
