# 手动物品栏布局与准星信息居中设计

## 目标

消除物品栏在屏幕角落反复切换横版和竖版的问题，并确保准星信息以自身中心为锚点显示和伸缩。

## 物品栏布局

- 完全移除基于屏幕边缘距离的自动横竖切换。
- 物品栏设置面板新增“布局”选择，选项为“横版”和“竖版”。
- 使用现有 `InventoryBarSettings::layout` 字段保存选择：`0` 为横版，`1` 为竖版。
- 初始化时直接恢复保存的布局，不再根据物品栏位置改变布局。
- 用户切换布局时，以当前物品栏中心为锚点换算新位置，再将窗口完整约束到屏幕内。
- 调整槽位大小时继续保持当前物品栏中心。
- 重置默认设置时恢复横版、50px 槽位，再定位到屏幕底部中央、距底部 20px。
- 配置结构和版本保持不变。

## 准星信息默认位置

- 默认和重置时，准星信息窗口的内容中心位于屏幕正中心上方 10px。
- 默认位置根据当前实际窗口尺寸计算，不把左上角直接放在屏幕中心。
- 无有效目标且窗口不可移动时继续不绘制；首次实际显示时完成默认定位。

## 准星信息中心伸缩

- 记录准星信息上一次已应用的实际窗口尺寸。
- 文本内容或字号导致窗口尺寸变化时，根据旧尺寸与新尺寸之差调整左上角，使窗口中心保持不变。
- 文本变宽时左右各扩展一半；变窄时左右各收缩一半。
- 高度变化时同样保持垂直中心。
- 用户通过 Alt 拖动窗口后保存新的位置；后续文字变化围绕用户拖动后的中心伸缩。
- 靠近屏幕边缘时，保持中心后再执行屏幕约束，优先保证窗口完整可见。
- “固定”与现有位置持久化行为继续保留。

## 纯逻辑与清理

- 新增或复用纯逻辑函数计算屏幕中心偏移位置和尺寸变化后的中心位置。
- 删除不再使用的自动物品栏方向判断函数及其边缘阈值测试。
- 保留横版/竖版尺寸、中心换算、屏幕约束相关测试。
- 新增准星默认中心上移 10px、文字变宽/变窄以及靠边约束测试。

## 验证

- 物品栏移动到任意角落时布局不再自动改变。
- 设置中切换横版/竖版只发生一次，并保持当前中心。
- 重启后恢复保存的布局。
- 准星信息默认中心为屏幕中心上方 10px。
- 不同长度信息切换时围绕当前中心向两侧伸缩。
- 用户拖动准星信息后，文本变化继续保持拖动后的中心。
- Debug、Release 构建和 CTest 通过。
- 最终构建到 `K:\ToolsBOX\out\bin\Release\PhasmophobiaInjector.exe`。
