# 物品栏非装备文字描边设计

## 目标

保证“可互 / 动物”文字在任意高光颜色下清晰可见。

## 设计

- 保持现有绘制顺序：槽位背景、高光填充、内容、边框。
- 仅为 `NonEquipment` 的两行白色文字增加 1px 黑色描边。
- 每行先在左、右、上、下四个方向偏移 1px 绘制不透明黑色文字，再在原位置绘制白色正文。
- 两行文字的 16px 字号、测量、居中和 2px 行距保持不变。
- 装备图片、空槽、Unknown、槽位序号、高光颜色和透明度均不改变。
- 不修改 V7 配置格式。

## 验证

- 先增加纯逻辑测试锁定四方向 1px 描边偏移，再实现最小辅助接口。
- 验证渲染代码在白色正文前绘制四次黑色描边。
- Debug、Release 全量构建和全部 3 项 CTest 通过。
- 更新默认 Release 注入器，不执行游戏注入。
