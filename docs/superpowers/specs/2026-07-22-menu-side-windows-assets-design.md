# 菜单侧窗、资源图片与程序图标设计

## 目标

缩窄主菜单，统一屏幕准星形状选择框宽度，增加跟随主菜单的按键说明和支持窗口，并为注入器设置程序图标。

## 屏幕准星设置

- “形状”选择框宽度固定为 100px。
- 与功能设置页中的字体和物品栏布局选择框保持一致。
- 不改变形状选项或配置格式。

## 主菜单尺寸

- 主菜单由 860×560px 改为 645×560px，只缩小宽度四分之一，高度保持不变。
- 左侧功能列表列宽由 238px 调整为 180px。
- 左侧列表 Child 宽度由 220px 调整为 162px。
- 右侧设置区域保留现有标签和控件宽度；内容超出时由 Child 滚动。
- 主菜单继续受屏幕边界约束，始终完整位于屏幕内。

## 左侧按键说明窗口

- 使用独立 ImGui 窗口，标题为“按键说明”。
- 窗口不可移动、不可缩放、不可折叠，并拥有标准标题栏关闭按钮。
- 固定跟随主菜单左侧，与主菜单间隔 10px，垂直居中。
- 显示以下内容：
  - U：显示/隐藏工具箱菜单
  - Alt + 鼠标左键：移动未固定的功能浮窗
  - I：手动开始圣木计时
  - O：清除圣木计时记录
  - P：清除十字架燃烧记录
  - 仅游戏窗口位于前台时生效
- 点击关闭按钮后，本次注入生命周期内不再显示；不写入配置。
- 下一次重新注入时恢复显示。

## 右侧支持窗口

- 使用独立 ImGui 窗口，标题为“支持作者”。
- 窗口不可移动、不可缩放、不可折叠，并拥有标准标题栏关闭按钮。
- 固定跟随主菜单右侧，与主菜单间隔 10px，垂直居中。

## 跟随、显隐与边界

- 每帧先绘制主菜单并获得本帧实际位置与尺寸，再定位和绘制左右侧窗，避免一帧跟随延迟。
- 使用主菜单本帧 Bounds 计算侧窗位置。
- 左右侧窗不执行屏幕 Clamp；当主菜单靠近屏幕边缘时允许侧窗部分或全部超出屏幕。
- 主菜单继续执行 Clamp。
- 按 U 或点击主菜单 X 隐藏主菜单时，左右侧窗同步隐藏。
- 重新显示主菜单时，仅恢复本次注入中尚未被单独关闭的侧窗。
- 两个侧窗跟随主菜单的暗色、亮色和深蓝主题。
- 侧窗主题应用后恢复通用样式，不污染功能浮层。

## 绘制层级

- 绘制顺序为：功能浮层、吸附参考线、主菜单、左右侧窗。
- 侧窗不参与 Alt 拖动、四宫格参考线或智能吸附。
- 参考线仍位于功能浮层之上，并由主菜单区域裁剪；侧窗不改变现有吸附计算。

## 赞助图片资源

- `resource/wx_zfb.png` 在构建期嵌入 payload，运行时不读取相对路径。
- 将现有 WIC/D3D11 内存 PNG 解码与纹理创建逻辑泛化为可接收任意内存 PNG。
- 原有 63 张物品栏贴图继续使用同一通用接口。
- 资源生成器额外输出独立的赞助图片数据，不改变物品栏资源索引和映射。
- Overlay 初始化时创建赞助图片 SRV，关闭时释放。
- 解码失败时支持窗口仍显示文字，但跳过图片，不崩溃。

## 程序图标

- 使用 `resource/favicon.ico` 作为 `PhasmophobiaInjector.exe` 文件图标。
- 在 injector 中增加 Windows RC 资源脚本并加入 CMake 目标。
- 保持 Console 子系统、入口点和现有启动方式不变。
- 图标只嵌入注入器 EXE，不修改 payload DLL。

## 配置兼容

- 侧窗关闭状态仅保存在进程内存，不加入 Settings。
- 不新增配置字段，不升级当前 V7 配置版本。
- 主菜单原有位置、主题和参考线设置保持兼容。

## 测试与验证

- 纯逻辑测试覆盖主菜单 645×560 尺寸和左右侧窗位置公式。
- 验证侧窗位置不执行 Clamp，允许产生负坐标或超出屏幕宽度。
- 验证赞助 PNG 签名、嵌入数据存在及原始尺寸 315×150；运行时按 252×120 显示。
- 验证屏幕准星形状 Combo 使用 100px 宽度。
- 验证左右侧窗关闭状态不写配置，并随主菜单显隐。
- 验证 Release EXE 包含图标资源。
- Debug、Release 构建和 CTest 通过。
- 最终构建到 `K:\ToolsBOX\out\bin\Release\PhasmophobiaInjector.exe`。
- 不执行游戏注入；三窗跟随、主题、图片显示和关闭行为需游戏内实际运行确认。
