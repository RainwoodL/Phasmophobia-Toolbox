# 准星信息位置与侧窗高度修复设计

## 目标

让按键说明和支持窗口与主菜单等高，修正三个准星物品名称，并消除准星信息位置在每次注入后的持久化偏移。

## 侧窗高度

- 按键说明窗口宽度保持 380px。
- 支持作者窗口宽度保持 430px。
- 两个侧窗的高度不再分别固定为 230px 和 390px，而是每帧使用主菜单的实际高度 `menuBounds.size.height`。
- 当前主菜单实际高度为 560px，因此两个侧窗均为 560px 高。
- 两个侧窗与主菜单顶部和底部完全对齐。
- 左右间隔继续为 10px。
- 保持跟随主菜单移动和显隐、跟随主题、单独关闭后本次注入不再显示、允许越出屏幕等现有行为。
- 侧窗内容保持顶部排列，不为填满高度增加额外内容或拉伸二维码。

## 准星物品名称

运行时名称映射修改如下：

- `抛物线麦克风` 改为 `收音器`。
- `电磁场读取器` 改为 `EMF读取仪`。
- `幽灵笔记` 改为 `鬼魂笔记`。

等级后缀保持现有规则：tier 0、1、2 分别显示一级、二级、三级。同步更新固定字体字形语料和字形测试，保证英文 `EMF`、中文“收音器”“读取仪”“鬼魂笔记”完整显示。

## 准星信息持久化偏移根因

准星信息窗口使用 `ImGuiWindowFlags_AlwaysAutoResize`。重新注入会创建新的 ImGui Context，新窗口首帧处于出现和内容测量阶段。当前代码立即把该帧尚未稳定的窗口尺寸保存为尺寸基准；下一帧真实尺寸形成后，代码将其误判为运行期尺寸变化，调用中心保持算法移动窗口并把新位置写入配置。因此每次注入都会再次产生并保存一次偏移。

## 修复行为

- 保留准星信息位置以窗口中心为基准的现有设计。
- 窗口处于首次出现/测量阶段时，不建立尺寸基准，不移动窗口，不写入配置。
- 窗口首次获得稳定尺寸时，只记录该尺寸作为基准，不移动窗口，不调用 `MarkDirty()`。
- 此后的真实尺寸变化继续调用现有 `CenterPositionForResize`，保持窗口中心不动。
- 物品名称长度变化、等级显示变化或字体大小变化后，窗口中心继续保持稳定。
- Alt 拖动、智能吸附、固定窗口、默认位置重置和视口 Clamp 行为保持不变。
- 如果保存位置超出当前视口，仍允许 Clamp 到屏幕内并保存必要修正。
- 不增加配置字段，不升级当前 V7 配置版本，现有持久化位置继续兼容。

- 将首次稳定尺寸与后续尺寸变化的判定提取为最小纯逻辑，以测试：

  - 首个稳定尺寸只建立基准、不移动；
  - 相同稳定尺寸不移动；
  - 后续尺寸变化触发中心保持；
  - 重新开始一个窗口生命周期后，保存位置不会因首帧测量改变。
