# 物品栏布局与视觉优化设计

## 目标

优化物品栏缩放、设置、重置和视觉效果，并修复透明功能窗口的可见内容无法精确贴到屏幕边缘的问题。

## 物品栏尺寸与缩放

- 槽位大小范围改为 50–96px，默认值改为 50px。
- 调整槽位大小时，以物品栏当前中心为锚点缩放，不再固定左上角。
- 缩放后的窗口必须完整位于屏幕内；靠近边缘时先保持中心，再执行屏幕约束。
- 横向和纵向布局均使用相同的中心锚定逻辑。
- 横纵布局切换继续保持窗口中心，并与尺寸缩放复用同一纯逻辑位置计算。

## 键位字号

- 设置面板移除物品栏字体大小选择。
- 键位数字字号由槽位大小线性计算：50px 对应 16px，96px 对应 34px。
- 计算结果使用字体仓库实际支持的字号，以最接近的可用字号绘制。
- 旧配置中的字体字段继续保留以兼容现有二进制配置，但不再由物品栏 UI 修改或用于决定字号。

## 重置行为

- 重置时先恢复默认槽位大小 50px 和横向布局。
- 新尺寸应用后，再按屏幕底部居中、距底部 20px 计算默认位置。
- 重置不会使用重置前的窗口尺寸计算默认位置。
- 保留功能当前启用状态。

## 屏幕贴边

- `ClampPosition` 继续保证窗口完整位于屏幕内，并允许窗口边界精确到达屏幕四边。
- 圣木计时器、游戏时间、鬼魂状态、十字架计时器和准星信息等透明文字窗口局部使用零 `WindowPadding`，使可见内容能够精确贴边。
- 物品栏继续使用零 `WindowPadding`。
- 主设置菜单保留现有内边距和视觉样式。
- 屏幕准星与玩家昵称不是可拖动窗口，不改变其定位行为。

## 物品栏视觉

- 每个槽位保持正方形直角，不使用圆角或半圆。
- 每个槽位绘制固定的深色半透明背景。
- 当前手持槽在深色背景上叠加轻微的高光色背景。
- 贴图在背景上等比例居中显示。
- 键位数字绘制在贴图上层。
- 最后绘制内层轻微亮边和外层边框；当前手持槽使用用户配置的 2px 高光边框。
- 绘制顺序固定为：背景、高光底色、贴图、键位、内框、外框。
- 本次不新增背景颜色设置，不升级配置版本。

## 配置兼容

- `InventoryBarSettings::slotSize` 默认值改为 50px。
- 加载旧配置时将槽位大小约束到 50–96px。
- 保留现有 `fontSize` 字段，避免改变配置结构与版本；物品栏不再读取它决定键位字号。
- 其他功能的位置、固定状态和设置保持不变。

## 测试与验证

- 纯逻辑测试覆盖 50/96px 边界、线性字号、中心缩放、靠边缩放约束、横纵尺寸和重置默认位置。
- 位置约束测试覆盖精确贴到左、上、右、下边缘。
- Debug、Release 构建和 CTest 均通过。
- 最终完整构建到 `K:\ToolsBOX\out\bin\Release\PhasmophobiaInjector.exe`。
- 游戏内验证连续缩放不漂移、重置后位于底部中心、所有透明功能可见内容可贴边，以及正方形槽位背景和高光效果。
